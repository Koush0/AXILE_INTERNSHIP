# Week 4 – Day 1: Backend Introduction (Flask)

## Objective
To create a basic backend server using Flask.

## Technologies Used
- Python
- Flask

## Steps Performed
1. Installed Flask
2. Created app.py
3. Defined route using @app.route("/")
4. Started local server

## How to Run

Install Flask:
pip install flask

Run server:
python app.py

Open in browser:
http://127.0.0.1:5000/

## Output
Displays: "Welcome to My Backend Server"

## Outcome
Successfully created and ran a basic Flask backend server.
