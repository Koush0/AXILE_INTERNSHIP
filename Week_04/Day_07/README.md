# StudentVault - Full Stack Project

## Live Website
Frontend (Netlify):
https://studentvaults.netlify.app/

Backend (Render):
https://studentvault-backend.onrender.com/students

## Features
- User Registration
- User Login
- Dashboard
- Add Student
- Edit Student
- Delete Student
- Backend connected with SQLite database

---

## Tech Stack
Frontend: HTML, CSS, JavaScript (Netlify)
Backend: Python Flask (Render)
Database: SQLite
