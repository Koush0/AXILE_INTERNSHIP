# Week 3 – Day 7: Final Mini Project  
## Smart Web Portal (Multi-Page Website in One File)

---

## Project Overview

This project is a multi-page web application developed using:

- HTML
- CSS
- JavaScript

All pages (Home, Registration, Login, Contact) are implemented within a single HTML file using JavaScript-based page switching.

---

## Features Implemented

### 1. Home Page
- Welcome section
- Navigation bar
- Clean and structured layout

### 2. Registration Page
- Input fields: Name, Email, Password
- Form validation
- Error alert if any field is empty
- Success message on valid submission

### 3. Login Page
- Email and Password fields
- Basic validation
- Success alert message

### 4. Contact Page
- Name, Email, Message fields
- Required field validation
- Success message after submission

---

## Technical Concepts Used

- DOM Manipulation
- Event Handling
- JavaScript Functions
- Conditional Statements
- Form Validation
- Class toggling for page navigation
- CSS styling and layout design

---

## UI Design Features

- Gradient background
- Card-based content sections
- Navigation bar with interactive buttons
- Hover effects
- Structured and professional layout

---

## Objective

To develop a mini web portal demonstrating frontend development skills using HTML, CSS, and JavaScript.

---

## Outcome

Successfully created a functional multi-page web interface with:
- Page navigation
- Form validation
- Interactive behavior using JavaScript
- Clean and modern UI design
